# Week 3 Backend — Office Management API

This folder organizes Week 3 learning material day by day.

## Structure
- Day 1–5: Topics already covered in the supplied learning files and conversation.
- Day 6–7: Starter files only; fill them as those lessons are completed.
- `app.js`: Main Express server.
- `routes/employeeRoutes.js`: Example Express router.
- `Day 4/employe.js`: Module example.
- `.env`: Local port configuration (ignored by Git).
- `.env.example`: Safe environment-variable template.

## Setup
```bash
npm install
npm run dev
```
Open `http://localhost:10000`.

## Important
MongoDB is not connected yet. Current routes return example responses and do not permanently save employee records.
