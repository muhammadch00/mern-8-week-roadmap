Before you start

Check your foundation before beginning Week 1.

FOUNDATION

🌐 HTML & CSS

  • HTML document structure and semantic tags
  • Links, images, lists, tables and forms
  • CSS selectors, classes and IDs
  • Box model, margin, border and padding
  • Flexbox, basic Grid and media queries
  • Build a responsive landing page independently

💻 Programming fundamentals

  • Variables, data types and operators
  • if/else conditions and loops
  • Functions, parameters and return values
  • Arrays, lists and basic objects
  • Break a problem into smaller steps
  • Read error messages and debug code

Quick self-check

Can you build a responsive two-section web page from scratch and write a function that finds the largest number in a list? If not, spend 1–2 weeks on freeCodeCamp Responsive Web Design and javascript.info — Part 1 first.

Weekly study routine

Consistency matters more than watching tutorials all day.

📅 Days 1–4 · Learn

Study concepts, type every example yourself, experiment with code and read official documentation.

🛠 Days 5–6 · Build

Build the week's mini-project without keeping a tutorial open. Push your progress to GitHub.

🌿 Day 7 · Review

Rest, revise difficult concepts and prepare for the next week.

Rules that make it work

  • Commit code to GitHub every day.
  • Debug for 20 minutes before searching for help.
  • Read documentation before relying on AI answers.
  • Use AI to understand errors, not to avoid learning.
  • Don't skip a checkpoint just to finish on time.
  • Adjust the schedule if a topic needs more practice.
